# Movie Booking System

## About the Project
The Movie Booking System is a Java-based application designed to manage movie bookings.

## Features
- Movie booking management
- Movie selection
- Booking information management

## Technologies Used
- Java
- Object-Oriented Programming

## Installation
1. Clone or download this repository.
2. Open the project in your Java IDE.
3. Run the main Java class.
